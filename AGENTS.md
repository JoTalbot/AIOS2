# Инструкции для AIOS агентов

## Назначение
Этот репозиторий содержит AIOS v2 — новую архитектуру проекта. Перед каждым изменением агент обязан прочитать `AGENTS.md`, `.agents/STATUS.md` и подходящие skills.

## Параллельная работа
- Работа выполняется разными агентами, с разных машин и параллельно.
- GitHub — источник истины для кода, документации и статуса.
- Перед каждым существенным шагом проверяйте `.agents/STATUS.md` и открытые PR/issues.
- Один агент — ограниченный ownership файлов/подсистемы; не переписывать чужую историю.
- Не делать force-push в общие ветки.
- Завершённый атомарный шаг: тесты/валидация → commit → push → обновление статуса.

## Архитектура v2
- AIOS2 является чистой линией новой архитектуры.
- Канонический flow: Intent → Planner → Scheduler → Agent → Tool Registry → Permission Boundary → Tool → Memory/Persistence → Reflection.
- Execution, persistence и recovery должны иметь единый canonical path.
- Любое изменение публичного контракта сопровождается regression test.

## Skills и документация
Перед реализацией проверять `.agents/skills/`, `docs/` и планы. Результаты исследований и повторяемые решения превращать в reusable skills/ADR.

## Handoff
После каждого существенного шага обновлять `.agents/STATUS.md`. Новый агент должен продолжить работу без предыдущего чата.

## Definition of Done
1. Проверены relevant skills.
2. Исследован текущий контракт.
3. Добавлены regression tests.
4. Пройдены доступные проверки.
5. Документация/status обновлены.
6. Изменения закоммичены в GitHub.
