# AIOS v1 Architecture

## Core Loop

Observe -> Execute -> Remember -> Evaluate -> Optimize -> Improve

## Layers

- Kernel: scheduling, context, memory, agents
- Runtime: execution, orchestration, recovery
- Agents: planning, lifecycle, swarm
- Memory: episodic, vector, knowledge graph
- Learning: reward, optimization, continuous improvement
- Security: sandbox, capabilities, audit

## Self Improvement

Experience flows through memory and learning systems to improve future agent strategies.

This document is retained as the historical architectural positioning from the original AIOS line. AIOS2 continues the same mission while replacing the execution foundation with the new durable orchestration architecture.
