# Skill: Coding

Reusable implementation workflow for AIOS2.

## Steps
1. Understand the requirement and the affected architecture boundary.
2. Research the current implementation and existing patterns.
3. Define a minimal change and claim ownership for its write set.
4. Implement without introducing duplicate state paths.
5. Add focused regression tests (required for public-contract changes).
6. Run validation.
7. Document decisions and extract reusable knowledge into
   `.uasep/knowledge/`.
