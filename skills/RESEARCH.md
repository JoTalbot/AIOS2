# Skill: Research

Structured research before AIOS2 architectural changes.

## Steps
1. Define the problem and the affected contract.
2. Search the current repository for existing solutions.
3. Review relevant documentation and repositories.
4. Record findings, alternatives, and tradeoffs.
5. Select the smallest compatible approach.
6. Record the decision as an ADR in `.uasep/decisions/` when it is
   architectural.
